GAMING TOURNAMENT PORTAL
=========================

Technologies:
- HTML
- CSS
- JavaScript
- Local Storage

Modules:
1. User Module
2. Admin Module

HOW TO RUN IN VS CODE
---------------------
1. Extract/open the "Gaming_Tournament_Portal" folder in VS Code.
2. Open index.html.
3. Recommended: install the "Live Server" extension in VS Code.
4. Right-click index.html -> Open with Live Server.
5. Create a user account using Sign Up.
6. Login with the new account to open user.html.
7. Admin demo login:
   Email: admin@gaming.com
   Password: admin123
8. Admin can add, edit and delete tournaments.
9. User can register for tournaments.
10. All users, login state, tournaments and registrations are stored in browser Local Storage.
